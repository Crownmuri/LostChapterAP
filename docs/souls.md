# What makes souls go up

Souls are the game's own play score (common event 72), counted live during a run:

    souls of the run = (score now - score the run started with) x soul_multiplier

- The run keeps the best value it reached, so spending gold or losing a stat never takes souls away.
- When a run ends its souls are banked. Banked souls plus the current run's, less what was spent, is the total.
- Nothing the multiworld hands you counts: received gold, stats, relics, cards taken from the deck screen and
  boons from the Boon Shop are all left out. The "10 / 25 / 50 Souls" filler adds to the bank directly.

The names below are the ones the game data uses. Rows marked DLC only exist with the DLC installed.

## Always counting

| Source | Score |
|---|---|
| Floor number | 1 per floor |
| STR, DEF, MAG, AGL | 1 per point |
| LEWD | 1 per point |
| Max LP, Max RP | 1 per 10 |
| Gold held | 1 per 10 |
| Sex counts (mouth, vagina, breasts, butt) | 1 each time |
| Sperm amounts (mouth, vagina, breasts, butt) | 1 per 10 |
| "Play Score Bonus" (variable 243, added by events) | as is, DLC |
